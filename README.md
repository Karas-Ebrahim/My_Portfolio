# Karas Ebrahim — Interactive Portfolio

A dark, developer-console-inspired portfolio built with Next.js, React, TypeScript and CSS.

## Features
- Animated hero and terminal typing
- Interactive VS Code-style Explorer and editor tabs
- Clickable folders and files with syntax-highlighted content
- Functional terminal commands: `help`, `ls`, `whoami`, `stack`, `projects`, `contact`, `cat <file>`, `clear`
- Interactive playground shell
- Projects, stack, experience timeline and contact sections
- Mouse-follow glow, hover states and scroll progress
- Responsive mobile layout

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

Deploy directly from GitHub to Vercel.
